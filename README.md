# КосмоХакатон 2026 — кейс "Проектирование устойчивой спутниковой группировки"

Сайт хакатона:
https://нн.космохакатон.рф

Демонстрационный сервер с разработанным сервисом:
https://cosmo-hack-front-verkhovma.amvera.io/

Веб-сервис "Спутниковод" - рабочее место проектировщика спутниковой группировки на круговых
орбитах 550 км. Сервис рассчитывает покрытие, межспутниковые связи (ISL), строит маршруты
«клиент → спутники → шлюз», анализирует перерывы, позволяет редактировать конфигурацию и сравнивать варианты сквозной доступности связи между наземными пунктами и шлюзом выхода в наземную сеть.

## Развертывание сервиса

### Требования

- Docker 24+ с Docker Compose v2
- 1 CPU, 2 ГБ RAM, 4 ГБ свободного места
- Порты `8080` (frontend) и `8000` (backend)

### Запуск

```bash
docker compose up --build
```

Frontend (Пользовательский интерфейс): http://localhost:8080

Backend Swagger (Документация API): http://localhost:8000/docs

### Остановка

```bash
docker compose down
```

## Инструкция пользователя

При первом заходе открывается стартовая страница:

    Слева — список примеров конфигураций

    Сверху справа — «Загрузить мою конфигурацию (JSON)»: загрузка пользовательского сценария.

    Снизу справа — «Начать с пустой конфигурации»: пустой сценарий, нужно добавить плоскости, спутники, клиентов и шлюзы вручную.

После определения конфигурации система проводит проверку ошибок и расчет параметров на сутки. 
- Положения спутников и наземных объектов, а также маршрут выбранного клиента отображаются на карте, под картой расположена шкала времени и диаграммы связи клиентов (видимость клиента спутниками и возможность проложить маршрут до шлюза).
- Справа расположены селектор клиента, метрики перерывов связи, рекомендации по повышению доступности, а ниже - статус отмеченного спутника.
- Сверху (слева направо) находятся управляющие кнопки: смена сценария, журнал действий, редактор конфигурации, выгрузка результата, перерасчет параметров, а также инструмент сравнения.
- Редактор конфигурации позволяет изменять параметры плоскостей, отдельных спутников, стадию запуска, настройки наземных пунктов, добавлять события выхода спутников и шлюзов из строя. Кнопка сохранения варианта добавляет текущие изменения к сравнению.
- Инструмент сравнения предлагает выбор из сохраненных вариантов и показывает рекомендованный по метрикам целевой доступности, средней доступности и перерывам связи.
